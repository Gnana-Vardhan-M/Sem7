# Sem 7 Exam Planner (PWA)

Works offline once opened. Your ticks and flashcards are saved on your own device only.

## Put it on GitHub Pages
1. Create a new public repository on GitHub (for example `sem7-planner`).
2. Upload all files in this folder to the repository root (index.html, sw.js, manifest.webmanifest, both icons).
3. Go to Settings > Pages. Under "Build and deployment" choose "Deploy from a branch", branch `main`, folder `/ (root)`. Save.
4. After a minute your app is at `https://YOUR-USERNAME.github.io/sem7-planner/`.

## Install on your phone
- Android (Chrome): open the link, tap the menu, then "Install app".
- iPhone (Safari): open the link, tap Share, then "Add to Home Screen".

## Changing the plan
Edit the `PLAN` list near the top of the script in `index.html`. If you change files after installing, bump `C='sem7-v1'` in `sw.js` to `sem7-v2`.
